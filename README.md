<summary>What these numbers represent</summary>

The Development Garden reflects verified GitHub and documented Digital EcoSystem activity.

**Releases** and **Commits** count releases and human-attributed main-branch commits across the selected repositories. **Merges** tracks merged pull requests in Digital EcoSystem. **Builds** combines distinct successful GitHub Pages deployments with independently verified local device builds—not 1:1 downloadable software releases. **Revisions** and **Test Sessions** are confirmed documented minima, not an exhaustive career history. **Projects** counts projects tracked by DES, while **Activities** counts tracked work items (including open ones).

The Garden updates only when measurable activity changes. It intentionally does not expose private project logs, chat content or local files.
